# 🧪 Data Science Projects

A collection of projects covering the core data science workflow: exploratory and statistical analysis, supervised classification, and unsupervised clustering.

## Projects

| Project | Question | Methods | Result |
|---|---|---|---|
| [ Healthcare EDA](healthcare-eda/) | What patterns and group differences show up in heart health and body performance data? | Visualization, t-tests, ANOVA | *A strong correlation coefficient between Systolic and Diastolic blood pressure is observed* |
| [ Spam detection](spam-detection/) | Can a message be classified as spam from its text alone? | TF-IDF, Naive Bayes, Logistic Regression | *best model: Naive Bayes* |
| [ Customer segmentation](customer-segmentation/) | What distinct customer groups exist in mall shopping data, and how should each be targeted? | K-Means, DBSCAN, Agglomerative clustering | Five income/spending segments with a tailored marketing action for each |

## Tech

Python · pandas · scikit-learn · SciPy · statsmodels · Seaborn · Matplotlib
